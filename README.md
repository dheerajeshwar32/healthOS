# HealthOS: Digital Health Care Dashboard 🩺📊

HealthOS is a responsive frontend web application designed to help users track their daily health metrics, including water intake, step count, calories, sleep, and heart rate. 

Developed as an academic web programming project at Vellore Institute of Technology by N. Dheeraj Eshwar

## 🚀 Key Features

* **Dynamic Tracking & Goals:** Log daily health metrics against customizable targets.
* **Data Persistence:** Uses the browser's `localStorage` to seamlessly save data across sessions without a backend database.
* **Voice Assistant:** Integrates the native Web Speech API for hands-free data logging (e.g., "add water").
* **Interactive Visualizations:** Uses `Chart.js` to render a dynamic weekly step-tracking bar graph.
* **Theme Toggling:** Instant Dark/Light mode powered by CSS Custom Properties.
* **Smart Advisor:** Built-in BMI calculator and dynamic health score generator based on daily progress.
* **Export Options:** WhatsApp sharing integration and PDF export support.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **Libraries:** Chart.js

## ⚙️ How to Run

1. Clone the repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Safari). No local server is required.
